## 2. 所处阶段判定

### 2.1 引擎内核：成熟（有可复核证据）

- 社会力参数对 Weidmann 基本图拟合，留出 RMSE 0.079 m/s，SFPE 独立对照 0.102 m/s，且自述「参数不唯一」。
- RiMEA 4.1.1 验证：15 建成 / **13 通过 / 2 披露的真实失败 / 1 无法建**。
- **GPU 步进核已真实接线（ADR-0033 stage 1–4 全部完成并真机验证）**：
  - 真实运行时切换：worker 内设备生命周期、`device.lost` 热降级回 CPU、fail-loud（同步 API 在 GPU 模式下拒绝静默跑 CPU）。
  - UI 有「GPU 移动(实验性)」开关 + `?gpumove` 门控，默认关。
  - 真机实测（Lovelace）：**交叉点约 750–1000 人**——低于它 CPU 更快，高于它 GPU 更快；1500 人时 CPU 均值 18.5 ms 已超 16.6 ms 帧预算，GPU 保持 ~6 ms 直到 2000 上限。
  - 调试过程真抓到两个物理缺陷（墙体力是线性近似、groupId 误传 -1），修复后引擎级 900 步差异从 0.48 m 收敛到 0.04 m。
- 行为面齐：多楼层/楼梯/扶梯/电梯、分时到达、结伴、排队（reneging/多级）、疏散（分楼层/反应时间/拥挤感知出口选择）、车辆 IDM、烟雾（自认非 CFD 近似）、实验扫描 + 蒙特卡洛、Sobol 敏感性、EnKF 到达率同化。
- 诚信治理是资产：CLAIMS_LEDGER 逐条改判历史过度宣称，所有面板 fixture 数据在 UI 里明标。

### 2.2 交付外壳：未完成

## 3. 可用性 / 易用性评审（按八维，三档评级）

| 维度           | 评级           | 要点                                                                                                                                                                                                                                                                              |
| -------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新手引导       | 可用但粗糙     | 首页有「四步做完一次仿真」+ 6 个行业模板画廊（真实几何缩略图）；但**全 UI 无帮助文档链接、无教程、无 onboarding tour**，专业参数（到达率/吸引力/停留均值）零引导                                                                                                                  |
| 编辑器交互     | 可用但粗糙     | 17 种工具、撤销重做、吸附、属性面板、GeoJSON/DXF/IFC/底图四路导入都有；**无复制粘贴、无多选**（选中态单值）、2D 撤销无快捷键、无 Delete 键删除；`transitStop.roadId`、`hazard.affectedRoadId` 仍需手改 JSON                                                                       |
| 持久化         | **有定时炸弹** | 单槽 localStorage（存新覆盖旧）；**底图以 base64 内嵌场景**（`SceneEditor.tsx:612`）必撑爆 ~5MB 配额；`saveScene()`（`SceneEditor.tsx:478`）**无 try/catch**（已复核）；**全 app 无 ErrorBoundary**（grep 零命中，已复核）→ QuotaExceededError 可直接白屏；无自动保存、无崩溃恢复 |
| 错误处理与降级 | 分裂           | 无 WebGPU：阻断卡 + 兼容模式徽章，**接近成品级**；SAB 不可用：明示降级 postMessage，好；但 **worker 崩溃只显示 Inspector 工程日志一行英文串**，无「仿真已停止/点击重试」的用户级 UI                                                                                               |
| UI 语言        | 成品级         | 全量中英 i18n（435 行消息表），双语首页/HUD 切换；瑕疵：部分技术词中英混杂                                                                                                                                                                                                        |
| 分析面板       | 接近成品级     | 5/9 fixture 面板**顶部明标「样例数据 · 与当前场景无关」**，误导风险低；但 `docs/PANEL_STATUS.md` 停在 6-19，与现 9 面板 registry 不符                                                                                                                                             |
| 性能与规模     | 可用但矛盾     | 2000 人硬顶（`crowdBudget.ts:20`）+ GPU 路径已接线但默认关；2D overlay 采样 500 人且有声明                                                                                                                                                                                        |
| 可访问性       | 基本处理       | skip-link、aria 全覆盖、reduced-motion、触摸基础；移动端只是窄屏堆叠，无专门触控模式（可接受，项目边界明说不做移动编辑）                                                                                                                                                          |

### 最影响商用的 5 个易用性问题（严重度降序）

1. **保存配额炸弹链**（P0）：base64 底图 → 无异常处理的 setItem → 无 ErrorBoundary → 白屏丢全部工作。
2. **模板规模承诺与引擎上限矛盾**（P0）：模板卡公开展示 `max 4500`（`industryTemplates.ts:253`），模板却不携带 `simulation.maxAgents`，worker 回落到 2000 硬顶（`simulation.worker.ts:110`，已复核）——**客户按 4500 人规划疏散，拿到的是被静默截断到 2000 的结果**。对安全咨询客户是可信度事故。
3. **「自己画场景」无学习路径**：模板→跑→看能走通；从零画场景对新手门槛陡峭（17 工具无解释、无复制粘贴、撤销快捷键只在 3D）。
4. **持久化单槽且手动**：无场景库/最近文件/自动保存，交付全靠用户记得导 `.csim.json`。
5. **故障态普通用户不可读**：worker 死了看到的是工程日志不是「请重试」。

## 6. 回答「能不能商用」

**分口径：**

1. **单机专业工具（本地授权给设计院/消防咨询，对标早期工程软件）**：**接近可卖**。补 P0 三条 + 部署路径 + 真 PDF，即可开始找 3–5 个种子用户（V2_PLAN 第 4 节本就计划如此）。当前体量：~55k 行 TS/TSX、~1300 测试、34 个 ADR，维护性已被最大文件 634 行 + 八道 CI 门禁证明。
2. **SaaS（云存储/分享/在线收费）**：**不能**。差整个 M7，且是数周至数月量级。
3. **消防审批口径**：**不能承担**。跨浏览器复现未建、真实轨迹标定未采纳、烟雾是自拟非 CFD 模型——报告只能「供决策参考」，这点 V2_PLAN 自己也写明了。

**建议路线**：P0 三条（约 3–5 天）→ 部署 + PDF（约 2–3 周）→ 以单机工具找种子用户 → 拿反馈决定是否重启 M7（backend 从 git 历史恢复，不必从零写）。
